## 🌟 Core Highlights

- **🎹 60fps Falling-Note Waterfall Piano Visualizer:** Synthesia-style in-browser practice with dual-hand color separation, **Do-Re-Mi (Solfège)** & **A-B-C** note labels, and automatic **1–5 piano fingerings**.
- **📡 Zero-Driver Bluetooth BLE-MIDI & USB MIDI Sync:** Standard MMA BLE-MIDI 1.0 support via Web Bluetooth & Web MIDI API for Yamaha, Roland, Casio, Kawai, Korg, and ESP32 MIDI hardware.
- **🎯 Wait-for-Key Smart Practice Coach:** Pauses playback until you strike the exact keys on your physical piano (via MIDI or microphone pitch detection).
- **🤝 Real-Time Multiplayer Collaboration:** Live jam rooms with synchronized playhead, collaborative score editing, and live remote keystroke visualization.
- **🔄 Open Industry Standards:** Full import/export for **W3C MusicXML 4.0**, **Standard MIDI (SMF)**, **MuseScore (`.mscx`)**, **Guitar Pro (`.gp`/`.gp5`/`.gpx`)**, **Vector SVG**, and **60fps Video**.
